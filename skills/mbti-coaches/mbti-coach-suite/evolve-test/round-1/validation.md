## 测试 2: 用户不确定类型（2 个快速问题）

**输入**:
```
我不确定自己是什么类型，能帮我判断吗？
```

**改进前输出**:
```
好的，帮你判断类型。回答 4 个问题：

1. 你更关注外部世界还是内心世界？（外向 E / 内向 I）
2. 你更关注事实细节还是整体模式？（感觉 S / 直觉 N）
3. 你做决定时更依赖逻辑还是情感？（思考 T / 情感 F）
4. 你更喜欢计划还是灵活？（判断 J / 知觉 P）
```

**改进后输出**:
```
好的，帮你快速判断。回答 2 个问题：

1. 充电方式：独处恢复能量（I）还是社交恢复能量（E）？
2. 做决定：先看逻辑（T）还是先考虑感受（F）？

选字母回答即可（如"IE"或"TF"）。
```

**对比**: ✅ 符合预期
- 改进：从 4 个问题→2 个快速问题
- 变化：问题更简洁，回答更简单
