### 2. 简化类型判断流程（P0）

**文件**: `SKILL.md` "类型选择引导"章节

**改动**:
```diff
- 回答以下问题，我帮你判断：
- 1. 你更关注外部世界还是内心世界？（外向 E / 内向 I）
- 2. 你更关注事实细节还是整体模式？（感觉 S / 直觉 N）
- 3. 你做决定时更依赖逻辑还是情感？（思考 T / 情感 F）
- 4. 你更喜欢计划还是灵活？（判断 J / 知觉 P）

+ 回答 2 个快速问题，我帮你判断：
+ 1. 充电方式：独处恢复能量（I）还是社交恢复能量（E）？
+ 2. 做决定：先看逻辑（T）还是先考虑感受（F）？
```

**为什么**:
- 4 个问题用户可能没耐心
- 2 个问题可快速判断 4 种可能（XT XF）
- 如无法确定再问第 3-4 题

### 3. 增加自动调用机制（P1）

**文件**: `SKILL.md` "类型选择引导"章节

**改动**:
```diff
- 直接调用对应类型的专属教练技能（如 `intj-coach`）
+ 告诉我类型，我**自动调用**对应教练技能（如"我是 INTJ"→自动调用 `intj-coach`）
```

**为什么**:
- 减少用户确认步骤
- 提升体验流畅度
- 符合"少问多做"原则
